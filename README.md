# ✨ Luminee

## Sistema SaaS para Salões de Beleza Femininos

Luminee é uma plataforma SaaS moderna e escalável criada para gerenciamento completo de salões de beleza femininos.

O sistema foi desenvolvido com foco em:

* Multi-tenant (vários salões usando o mesmo sistema)
* Personalização visual por cliente
* Gestão de agendamentos
* Controle financeiro
* Experiência premium
* Responsividade total
* Arquitetura escalável

# ⚙️ Instalação

## Clone o repositório

```bash
git clone https://github.com/Israelfre/Luminee.git
```

---

## Entre na pasta

```bash
cd Luminee
```

---

## Instale as dependências

```bash
npm install
```

---

## Execute o projeto

```bash
npm run dev
```

---

# 🔐 Variáveis de Ambiente
